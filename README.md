# React Blog Application

Учебный проект — простой блог с авторизацией, регистрацией и базовым функционалом управления постами.  
Проект реализован на **React** с использованием локального backend-сервера на базе **json-server**.

Цель проекта — отработка работы с React, роутингом, состоянием приложения, авторизацией и CRUD-операциями.

---

## 🚀 Функциональность

- Регистрация и авторизация пользователей (JWT)
- Просмотр списка всех постов
- Просмотр отдельного поста
- Создание нового поста
- Редактирование и удаление **своих** постов
- Добавление изображения к посту
- Комментарии к постам
- Просмотр списка пользователей
- Клиентский роутинг (React Router)
- Хранение данных в локальной базе (json-server)

---

## 🛠️ Используемые технологии

### Frontend
- React 18
- React Router DOM v6
- MobX (state management)
- Axios
- Bootstrap / React-Bootstrap

### Backend (локальный)
- json-server
- Node.js
- JWT (jsonwebtoken)
- Multer (загрузка изображений)
- Nodemon
